# Goldsvet

**Gaming platform and lobby engine framework.** Original, independently developed implementation.

## Overview

Goldsvet is a modular framework for building online gaming platforms:

- **Lobby engine** — configurable game lobby, categories, and search
- - **Player accounts** — registration, sessions, balance management
  - - **Wallet & transactions** — provider-agnostic wallet layer
    - - **Admin panel** — content management, player management, reporting
      - - **API-first** — REST API for every platform feature
       
        - ## Tech stack
       
        - - Backend: PHP 8 / Laravel
          - - Frontend: Vue 3 + Tailwind CSS
            - - Database: MySQL 8, Redis cache
              - - Queue: Redis / Horizon
